# Problem set 0 

## What is my scratch project about 

### English 
For my first Scratch program I tried to make a labyrinth, it works as simples as it is, your character is a bat and he is trying to make it to the end without touching the walls.
To get to the end, you have to get a key first, if you try to get to the end before getting the key, the bat will tell you to go back and get it.

I made the code by functions, first you have a function to make the bat move, another one to define when the key is obtained and when you obtain it, it will disappear. Then I have a function to define when you have to restart, that is when you touch the walls, I assigned that if the bat touches the color black he returns to the start. I also have a function to declare what is the initial position for the bat, and then I call that function when the wall is touched.
The win function works the same way the lose function does, but when you touch the color green and if you have the key.

I took about 2 hours plotting and constructing the program and had a lot of fun with it, I think it's good for a first Scratch project :)

### Português 
Para o meu primeiro projeto em Scratch tentei fazer um labirinto, funciona da forma mais simples possível. Seu personagem é um morcego e ele está tentando chegar ao final sem encostar nas paredes.
Para chegar ao final, você precisa primeiro pegar uma chave, se tentar chegar ao final antes de pegar a chave, o morcego dirá para você voltar e pegá‑la.

Fiz o código usando algumas funções; primeiro há uma função para fazer o morcego se mover, outra para detectar quando a chave é obtida — ao pegá‑la, ela desaparece. Depois há uma função que define quando é necessário reiniciar, ou seja, quando você toca nas paredes. Eu defini que, se o morcego tocar a cor preta, ele volta ao início. Também há uma função que define a posição inicial do morcego, e chamo essa função quando a parede é tocada. A função de vitória funciona de maneira semelhante à de derrota, mas ocorre quando você toca a cor verde e já possui a chave.

Levei cerca de 2 horas planejando e construindo o programa e me diverti muito; acho que ficou bom para um primeiro projeto em Scratch :)
