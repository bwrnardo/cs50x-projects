sort1 uses: Bubble Sort

How do you know?:It takes less time than the other sort types (Average Case), but when a file is already sorted it takes longer than simple adaptive sorts.

sort3 uses: Selection Sort

How do you know?: It does the same amount of work every time, even if it is already sorted.
